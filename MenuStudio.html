Menu Skin Studio

Menu Skin Studio

Design custom GUI textures for chest, hopper and dispenser menus. Tap slots to turn them into buttons, then export a resource pack.

Start from a look

Templates change the colors and style. Your layout, slot buttons and menu name stay as they are.

Slot buttons

Pick a paint tool in "Tool" above the preview, then tap or drag over slots. Hidden slots leave a gap for your own item art. These shortcuts use the selected brush.

Edit your own GUI texture

Upload a PNG of a chest, hopper or dispenser menu, such as a vanilla texture or one made in another tool. It replaces the generated look so you can rearrange it with Box select & move and add symbols with Icons. Frame, Fill and Slots settings are ignored while it is on.

Add symbols to your menu

Set Tool to "Icons: place & move", pick a symbol, then tap the preview to place it. Drag a placed symbol to move it. Picking a symbol or changing the color while one is selected changes that one; press Deselect to start a fresh one.

Replace the vanilla menu

Custom menu for a plugin

Gives each menu its own title glyph, so one chest can look different from every other chest. Add each design to the list, then save one pack that holds them all.
